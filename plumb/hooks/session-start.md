The plumb plugin is installed. Before acting on any request to plan, write, change, fix, test, refactor, review, audit, commit or ship code, however small, load the `plumb` skill (the charter) and the plumb phase skill whose description fits the request, both in the same turn, and follow them. When a request spans phases (build it, then commit it), load each later phase's skill before starting that phase. The charter's report, including its Decided line, ends every change.
